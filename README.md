# Spam Email Classifier

A text-classification project focused on distinguishing spam messages from legitimate email.

## Workflow
1. Document the dataset source, licence, labels, record count, and class balance.
2. Describe the actual text-cleaning and preprocessing steps.
3. Split the data before fitting the vectorizer to avoid vocabulary leakage.
4. Document the actual feature representation and classifier used.
5. Compare against a simple baseline.
6. Report precision, recall, F1, and a confusion matrix on held-out data.
7. Inspect false positives (legitimate email flagged as spam) and false negatives (spam missed).
